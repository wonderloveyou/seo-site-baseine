# SEO Site Baseline

Бесплатный skill для базовой SEO-проверки сайтов с помощью AI-агентов.

Он не изображает полный аудит по одному URL. Сначала агент фиксирует, к каким страницам, файлам и данным действительно получил доступ, а затем отделяет наблюдения от гипотез и предлагает проверяемый план действий.

## Что проверяет

- техническую доступность, статусы, redirects, robots и canonical;
- sitemap, индексируемость и конфликты директив;
- архитектуру, поисковые интенты и внутренние ссылки;
- Title, Description, H1, содержание, доверие и CTA;
- Search Console, Яндекс.Вебмастер и аналитику — если переданы проверяемые выгрузки;
- GEO и AI-трафик без смешивания визитов ботов, цитирований, переходов и лидов.

## Два способа использования

### 1. Как skill для AI-агента

Склонируйте репозиторий и положите его содержимое в каталог skills вашего агента. Для Codex проектная установка выглядит так:

```text
<project>/.codex/skills/seo-site-baseline/
```

После установки попросите агента, например:

```text
Проведи базовую SEO-проверку сайта https://example.com. Не делай выводов о данных, к которым у тебя нет доступа.
```

Точка входа — [`SKILL.md`](SKILL.md). Подробные правила лежат в [`references/`](references/), шаблоны — в [`assets/`](assets/).

### 2. Без установки

Откройте [`PROMPT.md`](PROMPT.md), скопируйте инструкцию целиком и передайте её ChatGPT, Claude, Gemini или другому ассистенту вместе с URL и доступными материалами.

## Что подготовить

Минимально достаточно URL. Для более сильной проверки пригодятся:

- приоритетные страницы;
- `robots.txt` и `sitemap.xml`;
- исходный или отрендеренный HTML;
- экспорт краулера с настройками и датой;
- выгрузки Search Console, Вебмастера, Метрики или GA4;
- описание продукта, региона, аудитории и главной конверсии.

Не передавайте пароли, cookies, API-ключи, токены сессий и ненужные персональные данные.

## Как устроен результат

Каждый существенный вывод проходит цепочку:

```text
artifact → observation → diagnosis → impact → action → verification
```

Неизвестное не превращается в «критическую ошибку». P0 допускается только для подтверждённой блокировки или широкого production-влияния.

## Проверка качества

Skill проверен на пяти сценариях: один публичный URL, robots + sitemap, локальный HTML, экспорт GSC и многостраничная локальная сборка. Результаты описаны в [`docs/forward-test-report.md`](docs/forward-test-report.md).

## Ограничения

По одному URL нельзя честно доказать состояние всего сайта, полноту индекса, каннибализацию, позиции или конверсии. Skill помогает определить границы доступных данных, найти воспроизводимые проблемы и составить план следующих проверок.
