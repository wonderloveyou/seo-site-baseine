# Architecture, intents, and internal links

## Page-intent matrix

Before recommending a new, merged, retained, redirected, or removed page, record:

| URL/proposal | Audience | User task or job to be done | Dominant intent | Funnel stage | Page type | Query cluster | SERP gate | Existing overlap | Business role | Decision | Dependencies |
|---|---|---|---|---|---|---|---|---|---|---|---|

One dominant commercial intent often maps to one canonical destination. Treat this as a working heuristic: informational pages can satisfy adjacent intents, and mixed SERPs can justify broader or provisional designs.

## SERP gate

Record query, locale, language, device when material, date, search surface, sampled results, dominant result types, and meaningful SERP features. Classify the proposed page type:

- `validated` — observed results consistently support it;
- `mixed` — multiple page types or intents remain viable;
- `contradicted` — observed results favor a different intent or page type;
- `provisional` — current SERP evidence is unavailable or insufficient.

When browsing is unavailable, keep the proposal provisional and specify the manual query/sample needed. A keyword list or search volume alone does not pass the gate.

## Architecture review

Check crawlable paths to priority pages, user-task hierarchy, orphan and dead-end evidence, true differentiation of segment/location pages, competing page purposes, useful hub/support relationships, descriptive natural anchors, breadcrumbs, and an explicit facet/pagination policy.

Classify link and overlap observations as URL-level, template-level, or sitewide only when the evidence sample supports that breadth.

Reject keyword-permutation architecture and doorway pages. Before merge, redirect, or deletion decisions, inspect intent, traffic, conversions, backlinks, replacement mapping, and dependencies.

## Module output

Return the page-intent matrix, SERP gate records, architecture and link observations with evidence IDs and breadth, important exceptions, overlap alternatives, and eligible candidates for retain, improve, merge, redirect, remove, or create decisions.
